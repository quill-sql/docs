## Updates

**Agent Chat is now schema-aware**

The in-app Agent now has access to your full virtual schema when answering questions and drafting reports. Expect more accurate suggestions, fewer follow-up questions, and better grounded answers about your data.

## Bug fixes

**Virtual table create and edit**

Resolved an issue that could prevent virtual tables from being created or saved correctly. Creating and editing virtual tables now works as expected. See [Create a virtual table](/bi-platform/virtual-table).

**Discard changes**

Fixed a regression where discarding in-progress edits did not always revert the editor to its last saved state.
