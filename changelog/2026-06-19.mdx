## New features

**Date bucketing for pivots.** When you pivot on a date column in the [Report Builder](/bi-platform/report#pivots), you can now group results by day, week, month, or year — no SQL changes required.

**Horizontal bar chart.** Horizontal bar is now its own chart type alongside column, line, and stacked bar. Select **Bar** in the chart editor to render values horizontally. See [Chart types](/bi-platform/report#editing-a-report).

**Radar chart.** A new **Radar** chart type is available in the [Report Builder](/bi-platform/report) for comparing multiple dimensions on a shared scale.

**Delete saved queries.** Saved queries can now be removed directly from the Saved Queries modal in the admin app.

## Bug fixes

- Fixed minor styling issues with [stacked bar charts](/bi-platform/report#editing-a-report), including spacing and label alignment.
- Improved decimal handling on chart axes so integer-only series no longer show fractional tick values.
