## Updates

**Pending changes stay in sync after environment switches**

When you switch environments or promote changes through the in-product AI agent, the list of pending changes now refreshes automatically. You no longer need to reload the page to see an accurate diff after resetting your sandbox, promoting work, or finishing an agent run.

Learn more about [environments and promotion](/bi-platform/overview).
