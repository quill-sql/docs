<Update label="June 23, 2026">
  ## New features

  **Duplicate reports in one click.** Open any report in your dashboard and use the new **Duplicate** action to instantly create a copy — including its chart type, columns, filters, pivots, and report builder state. Useful when you want to iterate on a variation of an existing report without rebuilding it from scratch. Learn more in [Create a report](/bi-platform/report).
</Update>
