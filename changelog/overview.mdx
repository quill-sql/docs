Follow along for the latest updates to the Quill platform and SDKs.

<Update label="June 8, 2026">

## Improvements

- **Loading indicators across the admin portal.** Promote, discard, environment save, environment delete, dashboard save, and dashboard delete actions now show a spinner while the request is in flight, so it's clear when an action is processing. Learn more in [Dashboards](/bi-platform/dashboard).

## Fixes

- **Editing an environment no longer triggers a refresh on cancel.** Closing the edit environment modal without saving previously reloaded the environment unnecessarily. Cancelling now leaves the current state untouched. See [Tenants and environments](/bi-platform/tenant).
- **Dashboard creation now works correctly in sandbox environments.**

</Update>
