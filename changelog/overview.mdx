<Update label="June 5, 2026">

## New features

**CLI chat diffs** — When you make changes through the CLI chat, Quill now shows a side-by-side diff of what's about to change before you apply it. Review additions, removals, and edits to dashboards, reports, and virtual tables in one place so you can confirm the result is what you expected.

## Updates

**Environment labels in the UI** — Environment changes (for example, switching between Development and Production) are now clearly labeled across the BI platform, making it easier to tell which environment you're working in at a glance. See [Environments](/bi-platform/overview) for how environments work.

**Refined changelog refresh** — The in-product changelog now refreshes automatically so you'll always see the latest updates without reloading.

## Fixes

**Normalization improvements** — Internal data normalization is more consistent, reducing edge cases where reports could render with mismatched values across environments.

</Update>
