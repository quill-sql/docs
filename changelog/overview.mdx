## May 26, 2026

### Bug fixes

- **Environment dropdown reliability.** Fixed several issues with the environment selector in the Quill admin portal. The dropdown now correctly displays your current source environment when an agent sandbox session is active, keeps the active environment pinned to the top of the list, removes duplicate sandbox rows, and hides legacy sandbox environments so the list stays focused on environments you actively use. See [Environments](/bi-platform/overview#1-environments) for how environments work.
