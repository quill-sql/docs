<Update label="June 10, 2026">
  ## Updates

  **Report builder temporarily removed from Admin.** The legacy report builder has been removed from the [BI Platform Admin](/bi-platform/overview) UI while we wire in the new version. Dashboards, saved queries, and the agent chat panel remain fully available.

  - The report builder entry point no longer appears in empty dashboards, the saved queries modal, or the agent chat panel.
  - Existing reports are unaffected. You can still view and embed them through the [React SDK](/react/quickstart).
  - The standalone `ReportBuilder` React component is still available — see the [ReportBuilder docs](/react/report-builder).

  A redesigned report builder is coming soon.
</Update>
