<Update label="June 9, 2026">

## Bug fixes

- **Multi-select filters now apply on close.** In the admin app, multi-select dropdowns no longer commit each selection individually. Changes are batched and applied when you close the dropdown, eliminating duplicate refreshes and inconsistent UI states. See [Dashboards](/bi-platform/dashboard).

</Update>
