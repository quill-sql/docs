<Update label="August 18, 2026" description="Week of August 18, 2026">

## New features

**Redshift support in the Node SDK.** You can now connect the [Server SDK](/server/quickstart) to Amazon Redshift by setting `databaseType: "redshift"` when instantiating `Quill`. Redshift uses the same connection string format as PostgreSQL and supports the full range of Redshift column types, including `super`, `varbyte`, `geometry`, `geography`, and `hllsketch`.

</Update>
