<Update label="June 18, 2026" tags={["New"]}>
  ## Edit Environment modal

  You can now edit, create, and promote environments from a single Edit Environment modal in the admin UI.

  **New features**

  - **Edit Environment modal** — A redesigned modal for managing an environment's name, database connection, and tenants in one place.
  - **Child environments** — Spin up a child of any environment to test schema or dashboard changes in isolation before pushing them upstream.
  - **Cross-environment promotion** — Promote changes from a child environment back to its parent in one click, so development → production handoffs no longer require manual re-creation of reports, dashboards, or virtual tables.

  Learn more about environments and how to use them in the [BI Platform overview](/bi-platform/overview).
</Update>
