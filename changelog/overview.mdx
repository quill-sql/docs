<Update label="June 19, 2026">

## New features

**Horizontal bar charts** — The [Chart](/react/chart) and [Report Builder](/react/report-builder) components now support horizontal bar charts as a dedicated chart type. Set `chartType` to `horizontalBar` to render categories along the y-axis, which is useful for long category labels and ranked comparisons.

</Update>
