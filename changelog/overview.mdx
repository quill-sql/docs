<Update label="June 19, 2026">

## New features

**Radar chart support**

You can now visualize multi-variable data with the new radar chart type. Radar charts are available wherever charts are configured, including the [`Chart`](/react/chart) component and the chart builder. Select **Radar** as the chart type to compare several metrics across categories in a single view.

</Update>
