## New features

### Automatic label formatting on charts

Chart axes, tooltips, and legends now automatically convert field names written in `snake_case` or `camelCase` into readable "Title Case" labels. For example, a column named `total_revenue` displays as **Total Revenue** with no extra configuration. This applies to [`Chart`](/react/chart), [`StaticChart`](/react/static-chart), and all bar, line, and radar chart variants.

## Updates

### Refreshed onboarding flow

The new-environment and database connection flow in the BI Platform has been streamlined. Connecting a database, choosing a schema, and creating an environment is now a clearer, more guided experience. See the [Quickstart](/bi-platform/quickstart) to get started.

## Bug fixes

- Fixed several small visual and validation issues in the database connection and schema selection steps of onboarding.
- Resolved an issue where the agent chat panel could mount before its context was ready.
